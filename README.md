# Panel de Docente Rector

Proyecto local e independiente para la Institución Educativa La Amistad. La página principal es el HTML de Funciones del Rector, con sus vistas originales y el Manual de Convivencia integrado en la pestaña correspondiente.

El Manual se monta como módulo React dentro de `index.html`; las demás secciones conservan su navegación y lógica original. El progreso del panel y los datos editables del Manual se guardan por separado en el almacenamiento local del navegador.

## Iniciar en local

```powershell
npm install
npm run dev
```

Para comprobar la versión de producción, ejecuta `npm run build`. No se ha publicado el proyecto en GitHub ni en Vercel.
